# Finance Agent Backend

TypeScript Express backend for the Finance Agent application.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Server runs on http://localhost:3000

## Build

```bash
npm run build
```

## Production

```bash
npm start
```

## API Endpoints

- `GET /` - Welcome message
- `GET /api/health` - Health check endpoint
